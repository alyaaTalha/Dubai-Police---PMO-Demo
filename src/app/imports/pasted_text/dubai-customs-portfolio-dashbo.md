Design a Portfolio Dashboard for the DG (Director General) inside a PMO / Portfolio Management System used by Dubai Customs.

The dashboard should provide clear executive visibility of all active programs and projects and allow the DG to quickly review portfolio health, project progress, and operational updates.

The interface should contain three tabs:

Executive Summary

General Overview

Detailed View

Each tab should present a different level of information granularity.

Use realistic sample project data related to Dubai Customs initiatives.

Page Header

Title:

Portfolio Dashboard

Subtitle:

Executive Overview – Dubai Customs Programs & Strategic Projects

Top actions:

Projects List
Create Project

Tab Navigation

Three tabs displayed horizontally:

Executive Summary
General Overview
Detailed View

Each tab reveals a different dashboard view.
