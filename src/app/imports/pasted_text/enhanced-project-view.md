Design an enhanced alternative view for the Detailed Project List inside the DG Portfolio Dashboard used by Dubai Customs.

The system currently contains a full EPMO-style project table with many columns, which should remain unchanged as the default view for compatibility with the existing EPMO Excel structure.

To improve usability and reduce excessive horizontal scrolling, introduce a second optimized project list view, accessible through a View Switch / Toggle.

View Toggle

At the top-right of the Detailed View page, include a View Selector.

Example options:

Table View
Enhanced View

The Table View should show the original EPMO table exactly as it is today.

The Enhanced View should present the same data in a more readable and structured format optimized for executive users.

Enhanced View Layout

The enhanced view should display the project list using a two-panel layout.

Left Panel – Project List
Right Panel – Project Details

This structure eliminates horizontal scrolling while still exposing all project information.

Left Panel — Project List

Display a vertical list of projects.

Each project appears as a compact project card containing the most important portfolio information.

Each card should display:

Project Name
Project Type
Status
% Completion
Next Milestone
Next Milestone Date
Owner

Example project card:

Customs Clearance Digital Transformation Program
Status: Progress Made
Completion: 67%
Next Milestone: Implementation Plan Draft
Milestone Date: Nov 21, 2025
Owner: Strategy & Future Department

Include a progress bar representing the percentage complete.

Include status indicators using colored labels:

Green – On Track
Yellow – Progress Made
Red – At Risk
Gray – On Hold

Allow clicking a project card to display its full details in the right panel.

Right Panel — Project Details

When a project is selected, display a detailed project information panel.

Organize the information into clear sections.

Section 1 — Project Information

Project Code
Project Description
Project Type
Status
Target Completion Date

Section 2 — Execution Updates

Latest Progress
Execution Update
Last Touchpoint

Section 3 — Milestones & Escalations

Next Milestone
Next Milestone Date
Request for Support

Section 4 — Governance & Ownership

Owner

Coordinator
